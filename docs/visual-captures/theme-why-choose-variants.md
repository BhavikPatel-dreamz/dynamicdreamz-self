# Shared Theme Why Choose Variants

- Date checked: 2026-09-01
- Scope: all pages using `ThemeWhyChooseSection`.
- The default and `gradient` background variant use
  `linear-gradient(97.18deg, #e8f9ef 28.5%, #e6fafd 91.82%)`.
- Gradient spacing is 50px vertical padding and bottom margin below 1024px,
  increasing to 80px at 1024px and above.
- The `white` variant supplies a white background and shared structural classes.
- Page content and layout props such as `variant`, `preserveDesktopTypography`,
  and `preserveLiveIconSize` remain page-specific.
- Existing explicit `className` values continue to take precedence for
  intentionally specialized layouts such as top-icon follow-up sections.
- Interaction states and animation timings: unchanged; this section has no
  variant-specific animation.
